# Task 1 Абстрактный суперкласс

**Описание**: библиотека фигур для рисования схем и конструкций на JavaFX. Реализованы: абстрактный Shape, фигуры (квадрат, эллипс, прямоугольник, крыша, забор, крыльцо, стена, окно), а также элементы блок-схем и логических схем (AND, OR, NOT и т.д.), каждая с визуализацией.

  - **Технологический стек**: Java с использованием библиотеки JavaFX. Приложение относится к категории Standalone desktop application (настольное самостоятельное приложение) — оно не зависит от сторонних фреймворков или экосистем (например, не требует Spring, не предназначено для интеграции в сторонние платформы).  
Работа с графикой осуществляется через компонент Canvas JavaFX.

## Зависимости
Для корректной работы приложения необходимо наличие следующих зависимостей:

1. Java Development Kit (JDK)
  • Версия: Java 11 или выше (рекомендуется Java 17+)
  • Более ранние версии Java (до 11) не поддерживают современные возможности JavaFX, используемые в проекте.

2. JavaFX
  • Версия: JavaFX 17 или выше (совместима с JDK 11+)
  • JavaFX больше не входит в стандартный JDK и должен быть установлен отдельно.
3. Среда разработки и сборки
• IntelliJ IDEA, Eclipse, NetBeans — любая IDE c поддержкой Java и JavaFX.
• Инструмент сборки (опционально):
• Maven или Gradle для автоматической загрузки зависимостей JavaFX и удобства управления проектом.
